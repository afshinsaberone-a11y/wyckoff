# وضعیت پروژه Wyckoff W0

هدف: توسعه و ارزیابی اکسپرت MT5 مبتنی بر وایکوف برای XAUUSD. این پروژه پژوهشی است و هیچ نسخه‌ای برای حساب واقعی تأیید نشده است.

## چارچوب
- زمینه H4 اختیاری؛ ساختار H1؛ تأیید ورود M5.
- خرید: Accumulation/Range → Spring → Test → SOS → LPS → تأیید M5.
- فروش: Distribution/Range → UTAD → Test → SOW → LPSY → تأیید M5.
- ریسک هدف گزارش‌شده: ۰٫۵٪؛ RR هدف: ۲٫۰.
- محیط تست گزارش‌شده: MT5، XAUUSD، WMMarkets-Demo.

## وضعیت نسخه‌ها
فایل‌هایی با نام v1.01 تا v1.07 در تاریخچه فایل‌های گفت‌وگو وجود دارند. وجود فایل به معنی کامپایل یا صحت عملکرد نیست. طرح BREAKOUT → RETEST → REJECTION → ENTRY صرفاً ایده آزمایشی است تا زمانی که سورس و تست متناظر بررسی شوند.
