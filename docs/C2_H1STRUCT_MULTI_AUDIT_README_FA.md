# H1STRUCT MultiLookback Audit v1.084 — راهنمای فارسی

## هدف

این نسخه فقط برای تشخیص و ثبت اطلاعات ساختاری H1 ساخته شده است. منطق معاملات نسخهٔ C2 حفظ شده و سفارش‌گذاری همچنان با مقدار `InpStrengthSwingLookback` داخل SET انجام می‌شود. این نسخه برای سنجش هم‌زمان سطوح محلی 5/10/20/40 و Pivotهای تأییدشده طراحی شده است.

## تفاوت با H1STRUCT Audit v1.083

هنگامی که یک کندل H1 معیارهای قدرت صعودی/نزولی را از نظر جهت، BodyATR، BodyShare و ClosePosition پاس کند، رویداد تشخیصی جدید ثبت می‌شود:

- `SOS_STRENGTH_BAR_AUDIT`
- `SOW_STRENGTH_BAR_AUDIT`

جزئیات هر رویداد شامل سطح High/Low قبلی با Lookbackهای 5، 10، 20 و 40 و نتیجهٔ شکست هر سطح است. همچنین سه Pivot اخیر با قاعدهٔ 2 کندل چپ و 2 کندل راست، تعداد Pivotها، پهنای ناحیهٔ سه Pivot در ATR و فاصله تا لبهٔ اصلی Range ثبت می‌شود.

**مهم:** سه Pivot اخیر فقط نامزدهای ساختار داخلی هستند؛ آن‌ها را نباید بدون بررسی چارت Creek یا Ice قطعی تلقی کرد. در این نسخه هیچ شرط معاملاتی بر اساس این Pivotها اعمال نمی‌شود.

## تنظیمات

از SET همراه استفاده کنید:

`Wyckoff_C2_H1StructureMultiAudit_2024_2026.set`

مقدار `InpStrengthSwingLookback=5` باقی می‌ماند تا مسیر معاملاتی مبنا با C2 قابل مقایسه باشد. فیلد CSV نام جداگانه دارد تا خروجی با Audit قبلی تداخل نکند.

## روش اجرا

1. سورس `Wyckoff_XAUUSD_W0_v1_08_C2_H1STRUCT_MULTI_AUDIT.mq5` را در MetaEditor باز و Compile کنید.
2. در Strategy Tester همین Expert را انتخاب کنید، نه نسخهٔ پایه و نه H1STRUCT v1.083.
3. نماد XAUUSD، تایم‌فریم M5، مدل Every tick based on real ticks، تاریخ 2024.01.02 تا 2026.11.04، Deposit=10000 USD و Leverage=1:200 را حفظ کنید.
4. SET همراه را بارگذاری کنید و یک اجرای مستقل انجام دهید.
5. HTML Report، Journal کامل و CSV را ذخیره کنید.

در CSV باید `EA_Version=1.08-C2-H1STRUCT-ML-AUDIT-SB050-T030` دیده شود. وجود `SOS_STRENGTH_BAR_AUDIT` و `SOW_STRENGTH_BAR_AUDIT` نیز نشانهٔ اجرای نسخهٔ درست است.

## آزمایش‌های بعدی

پس از ممیزی چند Lookback در یک اجرای ثابت، در صورت نیاز SETهای جداگانهٔ `SL10` و `SL20` را هم اجرا کنید تا اثر تغییر مسیر state machine سنجیده شود. SETهای 10 و 20 موجود با همین EA نیز سازگارند؛ نام CSV آن‌ها مستقل است.
