# بستهٔ ممیزی ساختار H1 برای C2 — بدون تغییر منطق معامله

## هدف
این نسخه از سورس C2 مشتق شده و صرفاً اطلاعات تشخیصی H1 بیشتری در Journal/CSV ثبت می‌کند تا قبل از هر تغییر راهبردی روشن شود:

1. Range واقعاً چه عرض قیمتی و چه عرض ATR دارد و ATR کندل سیگنال چقدر با ATR پیش از آن فرق می‌کند.
2. رویداد SOS/SOW صرفاً شکست Swing پنج‌کندلی است یا کل سقف/کف Range نیز شکسته شده است.
3. چند کندل بسته‌شده و چند ساعت از Test تا SOS/SOW گذشته است.
4. LPS/LPSY درون Range تأیید شده یا پس از عبور از مرز آن.
5. چند Setup با Test تأییدشده تا پایان عمر Range بدون Strength باقی مانده‌اند.

## نکتهٔ مهم
این نسخه عمداً هیچ شرط معاملاتی، ورودی، حد ضرر، حد سود، ریسک، حجم، ATR عملیاتی، تایم‌فریم، یا مرحلهٔ M5 را تغییر نمی‌دهد. فقط لاگ/CSV و یک شمارندهٔ تشخیصی H1 اضافه شده است. برچسب `RANGE_EDGE_BREAK` یا `INTERNAL_SWING_BREAK` فقط برای گزارش است و هیچ اثری بر پذیرش معامله ندارد.
